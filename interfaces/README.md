# Interfaces

Stable, documented hooks for working with the Coralia set C.

## Contents

| Directory | Purpose |
|-----------|---------|
| `grammars/` | Expression families (e/π-analytic, recurrence-defined, etc.) |
| `classifiers/` | Landing classification functions |
| `exports/` | Data in JSON, CSV formats |

## Usage

These interfaces are provided for reuse.
Results derived using them are not endorsed unless explicitly stated.
