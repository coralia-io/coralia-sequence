# Scope

## What This Repository Is

- A mathematically defined object (the Coralia Sequence)
- A verified computational library
- A reproducible research artifact

## What This Repository Is Not

- A theory of physics
- A cognitive model
- A metaphysical framework

(Unless explicitly stated in a paper)

## Structure

| Directory | Status | Meaning |
|-----------|--------|---------|
| `core/` | Authoritative | Papers, proofs, library, tests. Changes require version bump. |
| `interfaces/` | Reusable | Grammars, classifiers, exports. Use freely. |
| `sandbox/` | Exploratory | Domain applications. Inclusion ≠ endorsement. |
| `examples/` | Entry point | Simple demos. Start here. |

## On Cross-Domain Use

This project is designed to be reusable across domains.
Such use is encouraged.
Interpretations belong to their authors.
